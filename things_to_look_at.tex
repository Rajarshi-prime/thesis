\section{Errors in the physics}

\subsection{A dimensional mismatch in the relaxation time}
\apdx, line $437$, in the \actc\ appendix. The line reads
\begin{equation*}
  \tilde{\tau}^{-1} \equiv \frac{\mb{I}}{\tau}
  \left(\frac{\lVert\vec{v}-\vec{u}\rVert}{\beta^{2}} - 1\right)
  - (\alpha_{\rm act}\,\mathbf{S} + \mathbf{A}) .
\end{equation*}
Subtracting $1$ needs the first term in the bracket to be dimensionless. Here
$\beta$ is a rate, so $\beta^2$ carries inverse time squared, while
$\lVert\vec{v}-\vec{u}\rVert$ is a speed. Line $440$ writes the same bracket with
squared speeds, $(dr/dt)^2 + r^2(d\vartheta/dt)^2$, which suggests the numerator
should be $\lVert\vec{v}-\vec{u}\rVert^2$.




\section{Things that will print wrongly}




\subsection{A cross-reference to a section where a table belongs}
\apdx, line $362$, reads ``The Table \verb|\ref{act-AOUPvortex}| is a compilation
of data-sets\ldots''. The label \texttt{act-AOUPvortex} is defined on line $365$
on a \verb|\section|, so this prints a section number where a table number is
meant. The table intended is the one beginning on line $338$.

\subsection{A table label that cannot resolve}
\apdx, line $340$. The label \texttt{act-table\_organism} sits before the
\verb|\tabular| and the table has no \verb|\caption| at all, so the label picks
up whatever counter was last stepped. It would point at the wrong number even if
something referenced it.

\subsection{A placeholder label and an empty column}
\lcky, lines $409$ to $417$. The table of run parameters has an $\alpha_g$ column
with no values in any of its three rows, and a seventh column with no heading.
Its label is still the editor's default, \texttt{lucky-tab:my\_label}.




\section{Notation that misleads}

\subsection{A cell subscript on a whole-grid quantity}
\apdx, line $473$, in the \actc\ appendix. The line reads
\begin{equation*}
  {\Delta \rho_{ij}}^{2} = \frac{1}{N_{\rm bin}^2}\sum_{i,j} (\rho_{ij} - 1)^{2}.
\end{equation*}
The sum runs over every cell and is divided by the number of cells, so
$\Delta\rho_{ij}$ is one root mean square number for the whole grid. The $ij$
subscript makes it look like a quantity belonging to the single cell $i,j$, and
line $475$ reinforces that reading by explaining $i,j$ as the cell index. The
left-hand side should carry no $ij$. The fix touches both the equation and the
sentence after it.
