\section*{Notes}

\begin{enumerate}
  \item $\lambda_s$ for the depletion rate and $\alpha_g$ for the growth exponent in \texttt{polydisperse\_lucky\_drops} free $\gamma$ so it means the spectral slope in \texttt{thermalization} alone. $\beta$ was ruled out because \texttt{active\_caustics} already uses it for the swimming rate.
  \item $\gamma_\epsilon$ is proposed for the drag in \texttt{inertial\_caustics} while $\epsilon$ in that chapter becomes $\varepsilon$.
  \item $\mb{H}$ is proposed for the \texttt{thermalization} Hamiltonian and for the \texttt{active\_caustics} effective Hamiltonian. Both are Hamiltonians, so this is probably intended, but it should be stated rather than assumed.
  \item $\AR$ comes from the \texttt{ar} package, which \texttt{preamble.tex} does not load. It has to be added before the replacement is made.
  \item $N_g$ means collocation points in \texttt{thermalization} and grid resolution in \texttt{polydisperse\_lucky\_drops}. These are the same quantity, so the reuse looks deliberate.
  \item In \texttt{chapters/inertial\_caustics.tex} the tensors are written \verb|\mb{A}|, \verb|\mb{S}|, \verb|\mb{Z}|, and \verb|\mb| is defined in \texttt{preamble.tex} as \verb|\mathbb|. In \texttt{chapters/active\_caustics.tex} the same tensors are written \verb|\textbf{A}|, \verb|\textbf{S}|, \verb|\textbf{Z}|, with one stray \verb|\sf{S}|.
\end{enumerate}
